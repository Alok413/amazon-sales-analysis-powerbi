# Dataset

This folder contains the dataset used for the Amazon Sales Analysis Power BI project.

## Dataset Information

- File: Amazon_Combined_Data.xlsx
- Records: 89,082
- Time Period: January 2019 – December 2022
- Source Format: Excel

## Main Fields

- Product Category
- Product Description
- Price(Dollar)
- Number of reviews
- Shipment
- Order Date

The dataset is used for sales trend analysis, product category analysis, product performance analysis, and customer review analysis.
